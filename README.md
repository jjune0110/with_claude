# 학원 학생 관리 프로그램 (브라우저 화면 / 1단계)

학원 PC 한 대에서 실행하면 **브라우저로 접속하는 화면**이 열립니다. 별도 서버 구축이 필요 없고, 데이터는 `data/academy.db` 파일 하나에 저장됩니다.
**이 PC(127.0.0.1)에서만 접속할 수 있으며**, 학원 내 다른 기기나 인터넷에서는 접속되지 않습니다.

## 실행
| 환경 | 준비 | 실행 |
|---|---|---|
| Windows | Python 3.9 이상 설치 (설치 시 "Add python.exe to PATH" 체크) | `run.bat` 더블클릭 또는 `python run.py` |
| Linux | `sudo apt install python3` | `./run.sh` 또는 `python3 run.py` |

- 실행하면 기본 브라우저가 자동으로 열립니다. 열리지 않으면 `http://127.0.0.1:8765/` 로 접속하십시오.
- 검은 콘솔 창은 프로그램 본체입니다. **창을 닫으면 프로그램이 종료**됩니다. 종료는 화면 우측 상단 `프로그램 종료`(원장)를 권장합니다.
- 이미 실행 중이면 새로 띄우지 않고 실행 중인 화면을 엽니다. 포트를 바꾸려면 `python run.py --port 9000`
- 외부 패키지(pip)와 인터넷 연결이 필요 없습니다. 최초 실행 시 **원장 계정**(이름·PIN 4~6자리)을 만듭니다.

## 폴더 이동 (Windows → Linux)
프로그램 폴더 전체(`data/` 포함)를 복사하면 그대로 실행됩니다. 경로는 모두 상대 경로이고 DB 파일은 OS와 무관합니다.

## 1단계 기능
- 로그인(PIN), 무입력 자동 잠금(기본 10분, 서버에서도 세션 만료), 잠금·로그아웃
- 학생·가족·보호자·수업·특강·수강 등록
- 개인정보 열람 권한: 원장 + 담당 강사 (수강중 / 휴원 후 3개월 / 종료 후 1개월, 설정에서 조정)
- 가족 메모(500자, 주의 문구, 최종 수정자·수정일), 수정 이력(`audit_log`)

## 보안 설계
- 서버는 `127.0.0.1` 에만 바인딩하고, Host·Origin 헤더를 검사해 다른 웹사이트가 이 프로그램을 호출하지 못하게 막습니다.
- 로그인 세션은 무작위 토큰(HttpOnly, SameSite=Strict)이며, 개인정보 열람 권한은 **서버에서** 판정합니다. 화면 숨김에 의존하지 않습니다.
- 화면의 모든 값은 텍스트로만 출력하고(HTML 해석 안 함), CSP 로 외부·인라인 스크립트를 차단합니다.
- PIN 은 PBKDF2 해시로만 저장하며, 5회 실패 시 30초간 로그인이 제한됩니다.
- 접속 범위를 학원 내 다른 PC로 넓히려면 별도의 보안 설계(암호화 접속 등)가 필요하므로 현재 지원하지 않습니다.

## 폴더 구조
```
run.py / run.bat / run.sh   실행
app/main.py                 진입점 (서버 시작, 브라우저 열기)
app/db/                     DB 연결, 스키마(마이그레이션)
app/services/               권한 판정, 인증, 등록 처리 (화면과 무관한 규칙)
app/web/                    로컬 웹서버(server.py), JSON API(api.py)
app/web/static/             브라우저 화면 (index.html, app.js, style.css)
app/notify/                 알림 발송 채널 (3단계에서 구현)
data/                       DB 파일
backup/                     백업 (3단계에서 자동 백업 구현. 당분간은 data/academy.db 를 복사해 두십시오)
tests/                      점검용 테스트
```

## 점검
`python -m unittest discover -s tests -t . -v` — 권한 규칙, 접속 제한, 세션, API 권한 등 22개 항목을 확인합니다.

## 권한 요약
| 기능 | 원장 | 강사 |
|---|---|---|
| 학생 목록·수업정보·수강 내역 | 전체 | 전체 (조회) |
| 개인정보 | 전체 | 담당 학생만 (조회) |
| 가족·보호자·메모 | 전체 | 담당 학생이 속한 가족 (조회, 메모 수정) |
| 학생·가족·보호자·수업·수강 등록/수정 | 가능 | 불가 |
| 수업·특강(금액), 사용자, 설정, 프로그램 종료 | 가능 | 메뉴 숨김 + 서버에서 차단 |
